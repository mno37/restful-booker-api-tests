# Restful-Booker API Tests

Automated API test suite for Restful-Booker, a hotel booking API.

## Planned Coverage

- Authentication (token-based login)
- CRUD operations:
  - Create (POST)
  - Read (GET)
  - Update (PUT, PATCH)
  - Delete (DELETE)
- Negative test cases (400, 403, 404)
- Query parameters (filtering bookings)

- Newman
